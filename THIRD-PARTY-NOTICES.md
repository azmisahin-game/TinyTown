# Third-party notices

TinyTown itself is licensed under the MIT License. See `LICENSE`.

The release packages include the following third-party components. TinyTown does
not vendor source code from any of them; it links against them or uses them at
build time.

## SDL2 (runtime dependency on Windows, linked on Linux)

- Version used: 2.32.4
- Licence: zlib
- Purpose: window creation, keyboard and mouse input, and the OpenGL context.
- Homepage: https://www.libsdl.org/
- Licence text: https://github.com/libsdl-org/SDL/blob/release-2.32.4/LICENSE.txt

The Windows package bundles `SDL2.dll` because Windows has no system package
manager for it. The Linux package does not bundle SDL2; install it with your
distribution's package manager instead.

## OpenGL

- Provided by the graphics driver, or by Mesa on Linux.
- Licence: determined by the driver or by Mesa (MIT-style for Mesa).
- Purpose: drawing the scene.
- Homepage: https://www.mesa3d.org/

No OpenGL library is bundled in either package.

## zlib (optional, build-time)

- Version used: 1.3.1 (whatever the system provides)
- Licence: zlib
- Purpose: writing PNG screenshots. Without zlib the build writes PPM files
  instead, and the application still runs.
- Homepage: https://zlib.net/

zlib is linked at build time and is not bundled.

## Assets

TinyTown bundles no art, audio, font, or model files. Every shape in the town,
the bitmap font, and all colours are generated by code in this repository.

## No AI components

TinyTown v0.1.0 contains no language model, no speech synthesis, no image
generation model, and no model weights. The agents are rule-based task state
machines written in C++. See the roadmap in `docs/ROADMAP.md` for what later
milestones may add, as separate and optional work.
