## Hero

**TinyTown — a tiny world built from code.**

A compact C++ world laboratory: explore a procedural miniature city, watch autonomous agents do useful work, and turn a simulated scene into something you can capture and share.

No game engine. No mandatory AI model. Just a small, inspectable system that grows one proven capability at a time.

## Why TinyTown?

Modern software projects can become a maze of frameworks, services, model downloads, and build steps before their core idea works. TinyTown takes the opposite route: start with a visible, functioning world; keep the core understandable; add dependencies only when they solve a demonstrated problem.

## What it demonstrates

- **Procedural world-building:** buildings, streets, materials, and animation generated by code.
- **Autonomous behaviour:** agents navigate, carry out tasks, and expose their current state.
- **Local-first core:** the base experience does not need an AI model, account, or API key.
- **Creative output:** still capture and short scene export as those features become available.
- **Portability:** shared C++ logic, with platform support listed only after verification.

## Be precise about AI

Procedural graphics and code-synthesized ambience are not the same as AI-generated images or natural speech. TinyTown starts without an AI model. Optional image-generation, TTS, or LLM adapters may be explored later, with their hardware, licence, network, and runtime requirements documented.
